# Amazon L&G Pension Tracker

A static dashboard for tracking available Amazon Legal & General workplace pension funds.

The dashboard includes:

- Fund type grouping
- Management charge
- Fund introduction
- Indicative risk level
- Official factsheet links
- Monthly historical performance curves where available
- Fund comparison controls
- Portfolio simulator with percentage allocation

## Live Site

This project is designed to be published with GitHub Pages.

After GitHub Pages is enabled, the site will be available at:

`https://<github-username>.github.io/<repository-name>/`

## Data Notes

Performance data currently embedded in the dashboard is dated 8 Jun 2026.
Management charges were checked against L&G factsheet tables on 3 Jun 2026.

This dashboard is for tracking and comparison only. It is not financial advice.
